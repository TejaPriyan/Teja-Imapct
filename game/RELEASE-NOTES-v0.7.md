# v0.7.1 — Android compatibility update

The Android APK now targets Android API 36 and uses version code 8. This replaces the older API 32 build that Google Play Protect identified as outdated on current phones. The APK is still a directly distributed test build, so it has not been reviewed or distributed through Google Play.

# v0.7 — Play across screens

Adds a laptop/desktop browser edition, an Android ARM64 build path, landscape safe-area touch controls with independent move/look/attack gestures, enlarged mobile pause/settings controls, browser save synchronization and startup errors with a retry action. Adds a responsive game website with real gameplay images, controls, requirements, installation help, credits and verified downloads.

Fixes backup save recovery, accidental overwrite after failed Continue, point-blank ranged hits, fall recovery at the chosen checkpoint and stale effects on a new journey.

Windows retains two-player internet rooms. Browser and Android are solo and keep separate local progress. The Windows helper is excluded from phone/browser packages. iPhone/iPad remains unavailable without a Mac and Apple signing. See VALIDATION-v0.7.md for verified scope; no claim that all possible bugs or device-specific issues have been eliminated.
