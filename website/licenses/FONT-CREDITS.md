# Font credits — Teja's Impact v0.5

The interface bundles Rubik Regular for text and Rajdhani SemiBold for headings under the SIL Open Font License 1.1. Unity loads these files locally; no operating-system font installation or online connection is required.

- Source: https://raw.githubusercontent.com/google/fonts/main/ofl/rubik/Rubik%5Bwght%5D.ttf
- License: https://raw.githubusercontent.com/google/fonts/main/ofl/rubik/OFL.txt
- Bundled file: `Assets/Resources/Fonts/Rubik-Regular.ttf`
- Modification: static weight-400 instance produced with fontTools 4.61.1 for Unity's legacy font renderer. Family and style metadata identify the regular instance. No glyphs were removed.

Static-font tables and Latin UI glyph coverage were checked before Unity import. These notices apply only to the fonts; other asset licenses are unchanged.
